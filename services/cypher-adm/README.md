# CYPHERADM

## Descrição

Módulo central de administração e inteligência. Consolida dados de telemetria, gerencia o estado dos dispositivos da rede e expõe a interface de controle para os operadores de segurança.

## Requisitos Funcionais (RF)

- **RF01 - Exibição de Dashboard:** Fornecer painel em tempo real para visualização do status dos ativos e alertas críticos.
- **RF02 - Gestão de Aprovação de Dispositivos:** Permitir a aprovação ou rejeição manual de novos ativos com base no endereço MAC.
- **RF03 - Liberação de Quarentena com 2FA:** Exigir autenticação de dois fatores e justificativa textual para autorizar a remoção de um dispositivo do isolamento.
- **RF04 - Geração de Relatórios:** Gerar relatórios consolidados sobre tempo de indisponibilidade (downtime) e histórico de incidentes.
